# 1. Menggambar grafik dengan Seaborn
- Untuk memulai sebelumnya install dulu seaborn nya
> pip install seaborn

- kemudian import dulu site-package nya : 
> import seaborn as sns

- Jenis-jenis grafik yang bisa digunakan pada seaborn :
> sns.scatterplot(): Plot sebar (hubungan antara dua variabel numerik). </br>
> sns.lineplot(): Plot garis (tren dari waktu ke waktu atau data sekuensial). </br>
> sns.histplot(): Histogram (distribusi satu variabel numerik). </br>
> sns.barplot(): Plot batang (perbandingan antar kategori). </br>
> sns.lmplot(): Plot regresi linier.

- Membuat grafik dengan seaborn :
> sns.scatterplot(x='sepal_length', y='sepal_width', hue='species', data=df)
> sns.histplot(x='sepal_length', kde=True, data=df)
> sns.barplot(x='sepal_length', y='sepal_width', data=df)
> sns.boxplot(x="sepal_length", y="sepal_width", data=df, order=order, ax=ax)
> sns.pointplot(x="sepal_length", y="sepal_width", data=df, color = 'black', estimator=estimator, ax=ax)
