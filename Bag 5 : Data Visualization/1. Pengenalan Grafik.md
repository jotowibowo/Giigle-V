# 1. Menggambar grafik dengan Seaborn
- Untuk memulai sebelumnya install dulu seaborn nya
  > pip install seaborn

- kemudian import dulu site-package nya : 
  > import seaborn as sns

- Jenis-jenis grafik yang bisa digunakan pada seaborn :
  > sns.scatterplot(): Plot sebar (hubungan antara dua variabel numerik). </br>
  > sns.lineplot(): Plot garis (tren dari waktu ke waktu atau data sekuensial). </br>
  > sns.histplot(): Histogram (distribusi satu variabel numerik). </br>
  > sns.barplot(): Plot batang (perbandingan antar kategori). </br>
  > sns.lmplot(): Plot regresi linier.

- Membuat grafik dengan seaborn :
  > sns.scatterplot(x='sepal_length', y='sepal_width', hue='species', data=df) </br>
  > sns.histplot(x='sepal_length', kde=True, data=df) </br>
  > sns.barplot(x='sepal_length', y='sepal_width', data=df) </br>
  > sns.boxplot(x="sepal_length", y="sepal_width", data=df, order=order, ax=ax) </br>
  > sns.pointplot(x="sepal_length", y="sepal_width", data=df, color = 'black', estimator=estimator, ax=ax)

# 2. Matplotlib
- Untuk memulai sebelumnya install dulu matplotlib nya
  > pip install matplotlib

- kemudian import dulu site-package nya : 
  > import matplotlib as plt

- Jenis-jenis grafik yang bisa digunakan pada matplotlib :
  > plt.scatter(): Plot sebar (hubungan antara dua variabel numerik). </br>
  > plt.plot(): Plot garis (tren dari waktu ke waktu atau data sekuensial).

- Membuat grafik dengan matplotlib :
  > plt.plot(x, y, marker='o', color='blue', label='Garis Data') </br>
  > plt.scatter(x, y, color='blue') </br>

- Fitur matplotlib :
  > plt.title("Judul Grafik Sederhana") </br>
  > plt.xlabel("Sumbu X (Kategori)") </br>
  > plt.ylabel("Sumbu Y (Nilai)") </br>
  > plt.legend() untuk menampilkan label dari plt.plot() </br>
  > plt.grid() untuk menampilkan grid </br>
  > plt.ylim(bts_bwh,bts_atas) menentukan batas bawah batas atas grafik </br>
  > plt.xticks([1, 3, 5], ['Satu', 'Tiga', 'Lima'], rotation=45) mengubah nama x-axis </br>
  > plt.tick_params(axis='x', labelsize=10) mengatur ukuran font

- Ukuran grafik matplotlib : </br>
  Cara 1 :
  > fig = plt.figure(figsize = (10, 5))

  Cara 2 :
  > fig, ax = plt.subplots(figsize=(8, 8))

- Tampilkan grafik matplotlib :
> plt.show() akan membuka jendela baru menampilkan grafik. </br>
> plt.savefig("nama_file.png") akan menyimpan grafik ke file
