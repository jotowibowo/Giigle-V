Jika gagal, bisa dicoba cara ini, yaitu mendownload terlebih dahulu file site-package nya melalui link : https://pypi.org/
kemudian search site-package yang kita butuhkan lalu download ke dalam folder yang diinginkan. 
nanti untuk jenis file-nya ada 2 macam : filename.version.tar.gz ; filename.version.whl gunakan salah satu aja untuk pip install secara lokal.

![Screenshot](https://github.com/jotowibowo/Giigle-V/blob/c6d7a2ca9619cb39a8f0831e542718ff46cc34b3/image18.png)

sebagai tambahan, ada cara selain pip install yang dapat melakukan install melalui cmd dengan :

>    import subprocess
>    import sys
>    
>    def pip_all():
>        args = [sys.executable, "-m", "pip", "install", 'xgboost']
>        p = subprocess.run(args, check=True, capture_output=True)
>        return p.stdout.decode()
>    
>    print(pip_all())
</details>


> [!NOTE]
> pip install gagal bisa disebebkan oleh beberapa kemungkinan yakni : karena koneksi internet, pembatasan akses oleh Admin, adanya independency dari site-package lain, atau python yang old version.
