untuk menambah list bisa dilakukan dengan cara install new site-package dengan ketik : pip install site-package
jika hasilnya muncul seperti dibawah ini maka install-nya gagal yang kemungkinan karena koneksi internet, pembatasan akses oleh Admin, atau old version.
    Note: you may need to restart the kernel to use updated packages.
selanjutnya bisa dicoba cara kedua, yaitu didownload terlebih dahulu file site-package nya melalui link : https://pypi.org/
kemudian search site-package yang kita butuhkan lalu download ke dalam folder yang diinginkan. 
nanti untuk jenis file-nya ada 2 macam : filename.version.tar.gz ; filename.version.whl gunakan salah satu aja dengan cara ketik : pip install /folder/filename.version.tar.gz 
untuk install secara lokal.

sebagai tambahan, ada cara lain untuk pip install dapat dilakukan melalui cmd dengan cara ketik :
    import subprocess
    import sys
    
    def pip_all():
        args = [sys.executable, "-m", "pip", "install", 'xgboost']
        p = subprocess.run(args, check=True, capture_output=True)
        return p.stdout.decode()
    
    print(pip_all())
