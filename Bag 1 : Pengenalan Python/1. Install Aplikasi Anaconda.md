~~Setelah~~ selesai proses install kemudian masuk ke tombol _START Windows_ dan cari **Jupyter Notebook**.
Untuk cek versi dari Anaconda yang baru diinstall, ketik pada baris In[] : pip -V kemudian tekan [Shift] [Enter]
Respon yang didapat : pip <sup>25.3</sup> from C:\Users\00120878\Anaconda3\lib\site-packages\pip (python 3.9)Note: you may need to restart the kernel to use updated packages.
Artinya : versi dari Aplikasi adalah 3.9
Note : untuk aplikasi Anaconda disarankan untuk di ***upgrade*** secara berkala, karena aplikasi memerlukan site-package (akan dijelaskan pada pembahasan lebih lanjut) 
       yang diinstall secara kontinu. Untuk saat ini versi yang terbaru adalah 3.11 <sub>(Nov 2025)</sub>.

Untuk memulai script pertama, ketik pada baris -> In[] : print('Hello World') kemudian tekan [Shift] [Enter] untuk memproses.
Responnya pada baris berikutnya : Hello World
