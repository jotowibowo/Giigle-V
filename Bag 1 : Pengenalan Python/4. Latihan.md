2. Apa beda yang mendasar antara aplikasi jupyter notebook dengan visual studio code dalam hal mengeksekusi kode python?
<details>
<summary><b>Jawaban</b></summary>
  
> Perbedaan mendasar terletak pada interaktivitas dan alur kerja. Jupyter Notebook mengeksekusi kode secara non-linear dalam sel-sel individual, yang ideal untuk eksplorasi data dan prototipe interaktif dengan visualisasi inline. Sebaliknya, Visual Studio Code (VS Code) mengandalkan eksekusi skrip secara sekuensial (meskipun memiliki dukungan bawaan untuk menjalankan notebook Jupyter), yang lebih cocok untuk pengembangan kode produksi yang terstruktur dan bug-free. 
</details>
