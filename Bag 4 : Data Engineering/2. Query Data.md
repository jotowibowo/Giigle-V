## 1. Keep, Drop, dan Rename Column
- Untuk melakukan select column2 tertentu pada df bisa dilakukan dengan cara : 
  > df[['col1','col2','col3',...,'coln']]
- Sedangkan jika ingin melakukan drop column : 
  > df = df.drop(columns=['col1',...,'coln'])
- Sementara untuk distinct atau drop row yang duplicate bisa dilakukan dengan cara : 
  > df.drop_duplicates(inplace=True)
- Untuk rename column :
  > df = df.rename({'old1':'new1','old2':'new2',...,'oldn':'newn'},axis='columns')

## 2. Query pada DF
- Untuk query bisa dengan cara 
  - Cara 1 :
    > df.query('col1 > 30 and col2 == "New York"') </br>
    > df.query('col1 > 30') </br>
    > df.query('col==val',inplace=True)
  - Cara 2:
    > df[(df[col1]==val1) & (df[col3]>val3)] </br>
    > df[(df[col4]<=val4) | (~df[col5].isna())] </br>
    > df(df[col6].isin(val1,val2))] </br>
    > df.loc[df[col1].notnull()]

- Untuk mencari top/limit 10 :
  > df = df.head(10)
- Untuk mencari bottom 10 :
  > df = df.tail(10)

- Membuat case when dan membuat column baru :
  > df.loc[df["col1"].isnull(),"col_new"] = df["col2"] </br>
  > df.loc[df["col1"].notnull(),"col_new"] = 3 </br>
  > df.loc[~df["col1"]=='NEW',"col_new"] >= df["col2"]

- Sort column :
  > df = df.sort_values(['col1','col2',...,'coln'])
- Menjumlahkan beberapa column :
  > df["col"] = df[["col1","col2",...,"coln"]].max(axis=1)

## 3. Merge & Concat DF
- Untuk merge table :
  - Cara 1 :
    > df = pd.merge(df1, df2, left_on=(['key1']), right_on=(['key2']), how='left')
  - Cara 2 :
    > df = df1.merge(df2, left_on=(['key1']), right_on=(['key2']), how='left')

- Untuk concat table :    
  - Concat bisa digunakan sebagai perintah union :
    > df = pd.concat([df1,df2],axis=0)
  - Concat bisa juga digunakan untuk perintah merge asal kedua table bisa menggunakan index sebagai key join
    > df = pd.concat([df1,df2],axis=1)

## 4. Grouping dan Pivot DF
- Grouping table :
  > df = df.groupby(['col1','col2',..,'coln']).sum() </br>
  > df.columns = df.columns.droplevel(0) </br>
  > df = df.reset_index()
- Pivot table :
  - Cara 1:
    > df = pd.pivot_table(df1, index = ['col1',...,'coln'],columns=['col2'],aggfunc= {'col3': 'sum'})
  - Cara 2 :
    > df = df.groupby(["col1",..,"coln"],as_index=False).count().pivot("col1",...,"col2")
- Bikin total sum() pada orientasi column :
  > df['index'] = pd.Series(df['col1'].sum(), index=['index'])
