## 1. Fungsi IF: 

Pencabangan IF berfungsi untuk menentukan nilai yg TRUE saja. contoh sbb :
>if lulus == "tidak": </br>
>>   print("Kamu harus ikut ujian")

## 2. Fungsi IF/ELSE:
Pencabangan IF/ELSE berfungsi untuk menentukan nilai baik yang TRUE maupun yg FALSE sebagai alternatif pencabangan :
>umur = input("Berapa umur kamu: ") </br>
>if umur >= 18: </br>
>>    print("Kamu boleh membuat SIM") </br>

>else: </br>
>>    print("Kamu belum boleh membuat SIM")

## 3. Fungsi IF/ELIF/ELSE
Pencabangan IF/ELIF/ELSE berfungsi untuk pencabangan yang memiliki beberapa kondisi :
>nilai = input("Inputkan nilaimu: ") </br>
>if nilai >= 90: </br>
>>   grade = "A"

>elif nilai >= 80: </br>
>>   grade = "B+"

>elif nilai >= 70: </br>
>>   grade = "B"

>elif nilai >= 60: </br>
>>   grade = "C+"

>elif nilai >= 50: </br>
>>   grade = "C"

>elif nilai >= 40: </br>
>>   grade = "D"

>else: </br>
>>   grade = "E"

>print("Grade: %s" % grade)
