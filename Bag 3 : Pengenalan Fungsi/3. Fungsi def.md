# Cara Membuat Fungsi pada Python
> Fungsi pada Python, dibuat dengan kata kunci def kemudian diikuti dengan nama fungsinya.

Contoh :
>def nama_fungsi(): </br>
>>    print "Hello ini Fungsi"

![Screenshot](https://github.com/jotowibowo/Giigle-V/blob/533b2938df3e211e284df6f262482ba5601857e2/image28.png)

## 1. Fungsi dengan Parameter
Berikut untuk fungsi yang memiliki lebih dari 1 parameter.
Contoh :
>def luas_segitiga(alas, tinggi):</br>
>>    luas = (alas * tinggi) / 2</br>
>>    print "Luas segitiga: %f" % luas;

>luas_segitiga(4, 6)

## 2. Fungsi yang Mengembalikan Nilai
Cara mengembalikan nilai adalah menggunakan kata kunci return lalu diikuti dengan nilai atau variabel yang akan dikembalikan.
Contoh :
>def luas_persegi(sisi):</br>
>>    luas = sisi * sisi</br>
>>    return luas

>print "Luas persegi: %d" % luas_persegi(6)

## 3. Fungsi dengan Parameter Wajib
Contoh :
>def perkenalan (nama, asal): </br>
>>  print(f"Perkenalkan saya {nama} dari {asal}")

Jika dipanggil:

>> perkenalan("Renza Ilhami", "Jawa Timur")

## 4. Fungsi dengan Parameter Opsional
Contoh :
>def suhu_udara (daerah, derajat, satuan = 'celcius'): </br>
>>  print(f"Suhu di {daerah} adalah {derajat} {satuan}")
  
Cara panggil :

>suhu_udara("Surabaya", 30)

atau

>suhu_udara("Surabaya", 86, 'Fahrenheit')
