# 1. Looping dengan menggunakan fungsi FOR: 
- looping for dengan menggunakan element dari list :
  > my_list = ["apple", "banana", "cherry"] </br>
  > for item in my_list: </br>
  >>  print(item)

- Looping for dengan menggunakan index dari list :
  > my_list = ["apple", "banana", "cherry"] </br>
  > for i in range(len(my_list)): </br>
  >>  print(my_list[i])

- Looping for dengan menggunakan Keduanya (elemen & index) dari list :  
  > my_list = ["apple", "banana", "cherry"] </br>
  > for index, item in enumerate(my_list): </br>
  >>    print(f"Index: {index}, Item: {item}")


# 2. Looping dengan menggunakan fungsi WHILE:
- Looping dengan menggunakan syntax While :
  > my_list = ["apple", "banana", "cherry"] </br>
  > i = 0 </br>
  > while i < len(my_list): </br>
  >>    print(my_list[i]) </br>
  >>     i += 1
