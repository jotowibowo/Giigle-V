# 1. List Loop 
- looping dengan menggunakan element dari list :
  > my_list = ["apple", "banana", "cherry"] </br>
  > for item in my_list: </br>
  >>  print(item)

# 2. Range Loop 
- Looping dengan menggunakan index dari list :
  > my_list = ["apple", "banana", "cherry"] </br>
  > for i in range(len(my_list)): </br>
  >>  print(my_list[i]) </br>
# 3. While Loop
- Looping dengan menggunakan syntax While :
  > my_list = ["apple", "banana", "cherry"] </br>
  > i = 0 </br>
  > while i < len(my_list): </br>
  >>    print(my_list[i]) </br>
  >>     i += 1
