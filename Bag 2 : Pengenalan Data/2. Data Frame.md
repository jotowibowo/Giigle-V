## 1. Perbedaan antara data dan dataframe (df)
Data adalah kumpulan dari list. atau bisa juga dibilang list didalam list.</br>
Sementara Data Frame (df) dapat disebut dengan data 2 dimensi karena terdiri dari baris dan kolom.</br>
contoh :</br>
>data = [</br>
>        ['01','<0.20',0,0.00,0.00,0.00,0.00,10],</br>
>        ['02','<0.56',5,0.0450,0.00,0.0370,0.1111,8.2],</br>
>        ['03','<0.92',10,0.0901,0.0333,0.1296,0.0741,6.4],</br>
>        ['04','<1.28',37,0.3333,0.4000,0.3889,0.1481,4.6]</br>
>       ]

- Untuk mengubah data menjadi df dapat dilakukan seperti ini :</br>
  > import pandas as pd</br>
  > df = pd.DataFrame(data, columns=['grp','Ratio/Value','Frequency','Total','Trade','Manu','Service','FactorScore'])

- Untuk melihat hasil df dapat ketik :</br>
  > df or print(df)

- Cara lain untuk merubah data menjadi df :  
  > data = {</br>
  >        'grp' : ['01','02','03','04'],</br>
  >        'Ratio/Value' : ['<0.20','<0.56','<0.92','<1.28'],</br>
  >        'Frequency' : [0,5,10,37],</br>
  >        'Total' : [0.00,0.0450,0.0901,0.4000]</br>
  >        } </br>
  > df = pd.DataFrame(data=data)         

## 2. Konversi pada df
- Cara mengkonversi kembali dr column df ke list : 
  > df.col1.to_list()

- Jika ingin mengubah keseluruhan df menjadi string : 
  > df.to_string()

- Merubah data type column df :
  > df['col1'] = df['col1'].astype('int')</br>
  > df['col1'] = df['col1'].astype('str')</br>
  > df['col1'] = df['col1'].astype('float')

- Menampilkan df dalam bentuk html : 
  > display(HTML(df.to_html()))

- Merubah data type menjadi datetime : 
  > df = pd.to_datetime(df,format="%Y%m")
- Merubah datetime menjadi day week :
  > df.loc[df['col'].dt.dayofweek
- Memisahkan hari pada tanggal :
  > df.loc[df['col'].dt.days

## 3. Mengelola value pada df
- Memotong/memenggal value dalam column :
  - Cara 1 :
    > df['col2'] = df['col1'].str.slice(s0,s1)
  - Cara 2 :
    > df['col2'] = df['col1'].str[s0:s1]

- Memanggil cell tertentu dalam df :
  > df.iat[col2, row1]

> [!NOTE]
> column/row pertama dimulai dari angka 0

mengganti karakter dalam column : df['col2'] = df['col1'].astype(str).apply(lambda x: x.replace('.0',''))

mengisi cell kosong (N/A) dalam kolom
mengisi cell kosong dengan nilai 0 : df["col1"] = df["col1"].fillna(0)
mengisi cell kosong dengan karakter : df["col1"] = df["col1"].fillna('ada')
mengisi cell kosong dengan nilai row yang diatasnya : df = df.fillna(method='ffill')
mengisi cell kosong dengan nilai row yang dibawahnya : df = df.fillna(method='lfill')
menyamakan panjang karakter dalam kolom dengan cara mengisinya dengan nilai 0 didepannya sebanyak 2 digit : df['col2'] = df['col1'].str.zfill(2)
